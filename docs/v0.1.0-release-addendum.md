# v0.1.0 release notes addendum

The Local Apple Harness Adapter implements Harness Hub's training recipe in native MLX with real agent sessions and executable Harbor verifiers. This update documents the measured LFM3-1.7B BF16 and Pi experiment on one M4 Max Mac Studio. The adapter downloads and their checksums are listed on the release page. [Harness Hub experiment](https://huggingface.co/blog/harness-hub/harness-adapters) · [Adapter downloads and checksums](https://github.com/brendanboyle87/local-apple-harness-adapter/releases/tag/v0.1.0)

- **Evaluation.** The 30-task adapter passed 100/150 tasks and base passed 72/150, a paired gain of 18.67 percentage points (95% interval +10.27 to +26.97). Excluding three held-out tasks that share input bytes with training gives 97/147 versus 72/147, a gain of 17.01 points (+8.82 to +25.00). Each arm had one stochastic attempt per task. The 30-task arm ran after the reference arms on the same holdout. [Paired evidence and verifier outcomes](https://github.com/brendanboyle87/local-apple-harness-adapter/blob/main/results/lfm3-pi-breadth/README.md)
- **Training budget.** The released checkpoint inherited 24 warmup rollouts and used 400 main rollouts. The main phase applied 45 updates in 7.2 hours and peaked at 35.464 GiB in the MLX allocator. The frozen 30-task manifest lets reproductions skip the 376 shared screening attempts. [Training budget and manifest](https://github.com/brendanboyle87/local-apple-harness-adapter/blob/main/results/lfm3-pi-breadth/README.md#training-budget)
- **Gradient audit.** For the highest-drift group, the historical dense gradient and the sampling-shaped cached reference had cosine similarity 0.99687 and a relative L2 difference of 7.93%. Effects on other groups and the final weights remain open. [Group 41 audit](https://github.com/brendanboyle87/local-apple-harness-adapter/blob/main/results/lfm3-pi-breadth/README.md#group-41-gradient-audit) · [Historical source reconstruction](https://github.com/brendanboyle87/local-apple-harness-adapter/blob/main/results/lfm3-pi-breadth/historical-engine.md)
- **Evaluation checkpoints.** The updated runner saves a sampling-only checkpoint for collection and can resume older collection checkpoints. A same-configuration check with the released adapter reduced the serialized state from 263,569,036 bytes to 101 bytes per scored attempt.
